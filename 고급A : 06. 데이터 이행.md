● 0. 오라클의 데이터 이행 방법

① Direct Load Insert
   서브쿼리 INSERT
   /*+ append */ : HWM 위로 적재
   AS-IS → TO-BE 변환 : Direct load insert
      컬럼 추가/삭제, 마스킹/암호화, 데이터 정제
      서브쿼리로 변환 로직을 같이 태움

② SQL*Loader
   CSV / Text 파일로 DB 적재
   대량 적재에 많이 사용

③ Export / Import ( Data Pump)
   테이블ㆍ스키마ㆍ테이블스페이스 단위로 이행
   운영 이행에서 가장 흔한 방식

● 1. Direct Load Insert
  
구분          일반 INSERT                            Direct-path INSERT(append)
적재 위치     기존 블록의 빈 공간(가능하면 재사용)    주로 HWM 위 신규 블록
속도          상대적으로 느릴 수 있음                 대량 적재에서 빠를 수 있음
Redo/Undo     일반적으로 생성                        설정/모드에 따라 동작이 달라질 수 있음(로그/복구 관점 체크)
커밋          커밋 전에도 입력한 데이터를 볼수 있음   커밋을 해야 입력한 데이터를 엑세스 할수 있음

● 2. SQL*Loader : 외부파일 (.txt .csv)에 있는 데이터를 오라클 테이블로 대량 적재해주는 유틸리티

  - 다른 시스템의 데이터를 오라클로 옮기거나 파일로 받은 데이터를 한번에 적재
  - 로딩 규칙은 .ctl 파일(제어 파일)에서 정의
  - 컬럼 매핑, 구분자, 날짜 형식, NULL 처리 지정 가능
  - 동작 방식에 따라 일반 로드(Conventional Path), 고속 로드(Direct Path)로 나뉨


구성 파일

구성 요소             설명
Data file             CSV, Text, Excel 등 적재할 원본 데이터 파일
Control file (.ctl)   SQL*Loader가 읽는 제어 파일 (컬럼 매핑, 구분자, 날짜 형식, NULL 처리 등 로딩 규칙)
Bad file (.bad)       문법 오류 등으로 인해 로딩이 거부된 데이터
Discard file (.dsc)   문법은 맞지만 테이블 제약조건 등으로 인해 적재가 거부된 데이터
Log file (.log)       로딩 과정에서 수행된 작업 이력 (성공, 실패, 건수 등)

-- 테이블 생성
create table sample
( line_no    varchar2(20)
, time_inout varchar2(10)
, in_cnt     varchar2(10)
, out_cnt    varchar2(10) );



-- 컨트롤 파일 생성

$ vi sample.txt
  
options(skip=1)                    -- 첫번째행(컬럼명)은 생략
load data
infile '[HOME]/sample.csv'         -- 입력할 데이터 파일 위치와 이름 
into table sample                  -- 입력할 테이블명 
fields terminated by ','           -- 구분자를 콤마(,)
optionally enclosed by '"'         -- 옵션으로 데이터 중에서 더블 쿼테이션 마크가 있을 수 있음
(line_no, time_inout, in_cnt, out_cnt)



-- 데이터 이행
$ sqlldr [DB 유저명]/[DB 유저PW] control=sample.txt data=sample.csv -- direct=y 옵션 추가 시 Direct Path 방식으로 Load



-- 확인
$ cat sample.log

● 3. Export / Import

  - Dump : 단순하고 빠르게 데이터 이행
  - Pump : 대용량 데이터를 빠르게 이행 (약간 복잡)

  - Table Level      : 특정 테이블 Export / Import
  - User Levle       : 유저가 가지고 있는 모든 객체 Export / Import
  - TableSpace Level : 특정 테이블 스페이스를 통째로 Export / Import
  - Database Level   : Database를 통째로 Export / Import

● 3-1. Dump - Table Level
   
-- AS-IS : 12c -------------------------------------------------------------------------------------------

-- Export
$ exp file=hr_emp.dmp tables=employees    -- 사용자명/비밀번호 : hr/hr

-- 전송
$ scp hr_emp.dmp [TO-BE OS 계정]@[TO-BE IP]:[TO-BE에서 Import할 디렉토리]    -- yes / TO-BE의 비밀번호

----------------------------------------------------------------------------------------------------------

-- TO-BE : 19c -------------------------------------------------------------------------------------------

-- 테이블 스페이스와 유저 생성

create tablespace hr2_ts datafile '[HOME]oradata/hr2_ts01.dbf' size 100m;

grant connect,resource to hr2;
alter user hr2 default tablespace hr2_ts;
alter user hr2 quota unlimited on hr2_ts;
alter user hr2 quota unlimited on sysaux;

-- Import
$ imp system/oracle_4U file=hr_emp.dmp fromuser=hr touser=hr2 tables=employees constraints=n ignore=y

select count(*) from employees; -- 107건
