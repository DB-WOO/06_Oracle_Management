● 2. 테이블 스페이스 종류

① Permanent 영구 테이블 스페이스 : 사용자 데이터와 데이터베이스 객체를 영구적으로 저장하는 테이블스페이스
   테이블, 인덱스, 뷰, 프로시저 - 실제 객체 저장
   SYSTEM, SYSAUX, USERS .....
   Set as default permanent tablespace 체크 : 기본 테이블 스페이스로 지
  
② Temporary 임시 테이블 스페이스 : SQL 처리 중 임시 작업 공간으로 사용되는 테이블스페이스
   정렬, 해시 조인, 임시 결과셋 등 메모리 부족 시 디스크로 내려쓰는 공간
   세션 종료 시 데이터 자동 삭제
   성능에 직접 영향을 미치므로 대용량 정렬 쿼리 환경에서 크기 관리 중요
   Set as default temporary tablespace 체크 : DB 전체 기본 임시 테이블스페이스로 지정

③ Undo 테이블 스페이스 : 트랜잭션 롤백과 읽기 일관성을 위한 이전 데이터를 저장하는 테이블스페이스
   DML 수행 전에 변경 전 데이터 저장
   ROLLBACK시 이 데이터를 이용해 원상복구
   Flashback Query, 읽기 일관성 보장에도 활용
   Undo Retention Guarantee: Yes 설정 시 지정 시간 동안 Undo 데이터 강제 보존 (Flashback 활용 시 중요)
   Oracle 9i 이후 자동 관리 방식 (AUM) : 기본값 UNDOTBS1


구분         저장 내용                 영속성                     대표 예
Permanent    테이블, 인덱스 등 객체    영구                       USERS, SYSTEM
Temporary    정렬, 해시 작업 공간      임시 (세션 종료 시 삭제)   TEMP
Undo         변경 전 데이터            보존 기간 내               UNDOTBS1

● 3. 테이블 스페이스 상태

① Read Write
   DML, SELECT 허용
   정상 운영 상태
   테이블스페이스 생성 시 기본으로 설정되는 상태

② Read Only
   SELECT만 가능
   히스토리성 데이터 보호
   백업 부담 감소 → Read Only로 설정하면 변경이 없으므로 매번 백업 불필요
   데이터 이관/마이그레이션 시 원본 보호
   
   ALTER TABLESPACE inventory READ ONLY;

③ Offline
   테이블스페이스를 완전히 비활성화  →  접근 자체가 불가
   해당 테이블스페이스의 데이터파일 유지보수, 복구 작업 시 사용
   Offline 상태에서 RMAN 복구 후 다시 Online으로 전환
   SYSTEM 테이블스페이스는 Offline 불가

   ALTER TABLESPACE inventory OFFLINE;
   ALTER TABLESPACE inventory ONLINE;


상태        SELECT  DML   용도
Read Write  ✅	    ✅    일반 운영
Read Only   ✅	    ❌    데이터 보호, 백업 최소화
Offline     ❌	    ❌    유지보수, 복구 작업 






- Datafile 위치 변경 시 OFFLINE

  from dba_data_files

alter tablespace ts703 online;   -- 온라인




  ※ 테이블 스페이스 OFFLINE 옵션 4가지

  ALTER TABLESPACE tablespace_name OFFLINE [NORMAL | TEMPORARY | IMMEDIATE | FOR DROP];

  ① NORMAL : 기본값
     체크포인트 완전 수행 후 Offline
     Online 복귀 시 미디어 복구 불필요
     파일 이동/유지보수 목적으로 가장 많이 사용

  ② TEMPORARY
     체크포인트 일부만 수행
     Online 복귀 시 미디어 복구 필요할 수 있음
     일부 데이터파일에 I/O 오류 발생 시 사용
     
  ③ IMMEDIATE
     체크포인트 전혀 수행 안 함, 즉시 Offline
     Online 복귀 시 반드시 RMAN 미디어 복구 필요
     ARCHIVELOG 모드에서만 사용 가능
  
  ④ FOR DROP ( 바뀜 )
     테이블스페이스를 삭제하기 위한 목적으로 Offline
     데이터파일이 이미 손상/삭제되어 NORMAL, TEMPORARY, IMMEDIATE 모두 안 될 때 사용
     9i 이후에는 DROP TABLESPACE INCLUDING CONTENTS AND DATAFILES 로 대체됨
