● 1. NOMOUNT

  - SGA 할당
  - Background Process 실행
  - Parameter File (= PFILE / SPFILE)  →  DB INSTANCE를 메모리에 올림 
  - DB가 존재하지 않더라도 인스턴스를 띄워 CREATE DATABASE (생성), 손상 컨트롤 파일 복구 가능

startup nomount
select name, value from v$parameter;  -- 조회 가능
select name from v$database;          -- ORA-01507: database not mounted
select file_name from dba_data_files; -- ORA-01219: database or pluggable database not open .....
select name from v$datafile;          -- ORA-01507: database not mounted
select name from v$controlfile;       -- no rows selected


  
  
# nomount 상태에서 복구 -   백업

startup force

$ rman target / nocatalog
RMAN> configure controlfile autobackup on;    -- 컨트롤 파일, 서버 파라미터 파일 자동 백업 활성화
RMAN> backup database;


  

# nomount 상태에서 복구 -   컨트롤 파일   ① 위치 확인  ② 삭제  ③ startup force (장애 발생)
